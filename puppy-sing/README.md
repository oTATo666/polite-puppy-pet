# 🐶 礼貌小狗·唱歌

让桌面小狗**实时唱歌**的小应用：本地低延迟合成 + 联网热歌榜自动更新 + 自动学习演唱。

---

## 它怎么满足你的四个要求

| 你的要求 | 这里的实现 |
| --- | --- |
| **实时语音合成、低延迟快速反应** | 默认用「本地旋律合成引擎」：`numpy` 在内存里实时把旋律渲染成 WAV，**点击即唱、零模型加载、零网络等待**。热歌入队后在后台**预渲染并缓存**，点唱时直接播放，延迟 < 200ms。 |
| **接入网络实时获取网红歌曲列表** | 启动即在后台调用公共热歌榜接口（抖音热歌榜 / 网易云热歌榜，`api-hot.imsyy.top`，免密钥）。界面「🔄 刷新热歌榜」可手动刷新；「自动更新曲库」每 10 分钟自更新。接口不可达时**自动回退到本地缓存 / 内置榜**，程序永不空库。 |
| **自动学习并合成演唱热门歌曲** | 热歌入队即视为「想唱」。对有授权歌词+旋律的歌（内置原创 demo 与后续接入的授权曲）自动预渲染缓存；对受版权保护的歌，在拿到授权数据前标为「🔧 待学习」，用「生成专属旋律 + 报歌名」的方式演唱，**不擅自复刻原唱录音**。 |
| **演唱响应迅速且曲库持续更新** | 预渲染缓存保证响应迅速；后台定时拉榜 + 合并新歌，曲库随网络持续更新。 |

## 运行

```bat
# 方式一：双击
run.bat

# 方式二：命令行
pip install -r requirements.txt      # 默认只需 numpy
python main.py
```

> 需要 Windows + Python 3.10+（tkinter 为标准库自带）。也可直接复用桌宠项目的 `.venv`。

## 👂 扒歌学习（让小狗自己学会唱歌）

选中一首歌 → 点「**👂 扒歌学习**」→ 给一个音频来源（本地文件最稳，或热歌榜链接）→ 小狗自动完成：

```
音频 → ① 分离伴奏/人声 → ② 人声提旋律(pyin 音高轨迹→音符) → ③ 写入曲库 → 点「唱！」用小狗声线唱
```

- **分离后端自动择优**：装了 `demucs` 用 demucs（质量最好）；没装走**零依赖 mid/side 分离**
  （人声≈中置声道，伴奏≈侧声道，纯 numpy，任何机器都能跑）。
- **旋律是真旋律**：`librosa.pyin` 从人声提取逐帧音高，合并成音符、量化到拍，不是随机生成。
- **歌词两种方式**：默认用「啦」哼唱旋律（不复制歌词文本）；勾选「本地 ASR 认歌词」用 faster-whisper
  识别（首次自动下载小模型），或在框里填**授权歌词**逐字对齐到旋律。
- **扒完即唱**：学完自动预渲染缓存，点「唱！」零等待；三种引擎（本地/F5 原声/GSV）都能唱。

命令行也能用：

```bat
python ear_train.py <音频文件或URL> --title 歌名 --artist 歌手
python ear_train.py <音频> --lyric "授权歌词..."    # 逐字对齐唱出字
python ear_train.py --selftest                     # 无头自测（合成已知旋律验证闭环）
```

## 三种演唱引擎

- **本地旋律引擎（默认，零依赖/低延迟）**：用谐波+颤音+ADSR 包络合成「类人声」音，按旋律音高实时生成。内置原创歌曲能真正唱出歌词；热歌无授权歌词时，用歌名生成「专属旋律」哼唱（同一首歌旋律固定、不同歌各异），并标「待学习」。
- **edge-tts 真实语音（可选）**：`pip install edge-tts playsound` 后，在界面切换为「edge-tts 真实语音」。每个音节按对应音高用微软中文语音合成并拼接，得到「会唱的语音」。联网时后台预渲染，点唱即播。
- **🐶 小狗原声 F5 引擎**：直接复用桌宠已内置的 **F5-TTS 语音克隆**（`tools/f5_server.py`）。在界面选「小狗原声(F5克隆)」后，唱歌模块会把歌词按乐句发给 f5_server，合成**小狗自己的声线**，再按旋律映射音高拼接成歌。若 f5_server 未启动，模块会自动用 `voice-clone-env` 拉起它；若环境无 F5（未装/无显卡），则**自动降级到本地引擎**，保证「一定能唱」。

### 📝 学习一首歌（填入授权歌词）

对热歌榜里标「🔧 待学习」的歌，点「📝 学习这首歌」→ 粘贴该曲的**授权歌词** → 选旋律风格（抒情/欢快/下行/随机）→「保存并学习」。程序会用 `auto_melody_from_lyric` 把歌词自动编成旋律（每个字映射到音高），标记 `licensed + learned`，之后即可用任意引擎演唱出**真实歌词**。这就是"自动学习并合成演唱"的可落地闭环——你提供授权歌词，小狗学会唱。

> 未提供授权歌词前，热歌仅以生成旋律+报歌名方式演唱，不擅自复刻原唱录音（见文末版权说明）。

## 文件结构

```
puppy-sing/
├─ main.py              # tkinter 界面
├─ core.py              # 歌曲模型/曲库/热歌拉取/本地+edge+F5 三引擎/自动编旋律/播放
├─ data/
│  ├─ songs.json        # 内置原创 demo 曲库（真实歌词+旋律）
│  └─ trending_cache.json  # 热歌缓存（自动生成）
├─ cache/               # 合成音频缓存（自动生成，点唱零等待）
├─ requirements.txt
└─ run.bat
```

## 版权与边界说明（重要）

热歌榜只用于**获取歌名/歌手作为「想唱队列」**，属合理使用。对真实受版权保护的录音，**不会**在缺乏授权歌词/旋律数据的情况下合成并复刻。内置均为**原创**歌曲用于真实演唱示范；如需让小狗演唱某首热门歌，请提供该曲的授权歌词与旋律数据（写入 `data/songs.json` 或接入授权曲源），程序会自动学习并合成。这样既能持续唱新歌，又守住版权边界。

礼貌小狗桌宠 · 使用说明（升级版 2026-10-23）
==========================================

【这次先做一步：重建 exe】
桌面快捷方式指向 PolitePuppy.exe，但旧 exe 里打包的是旧页面，
直接替换文件夹里的文件是换不掉的。二选一：

  方式 A（推荐，10 秒）：右键 build.ps1 → 使用 PowerShell 运行，
        等它生成新的 PolitePuppy.exe，快捷方式照旧双击。
  方式 B：双击 run.bat 直接用源码跑新版（需要 Python 3.10+，
        第一次会提示装依赖：pip install -r requirements.txt）。

【新版多了什么】
- 输入框左边多了麦克风：点一下说话（中文，边说边出字），
  再点一下停，文字填进输入框，点发送。
- 底部快捷回复会跟着她的回复动态变，点一下直接发送。
- 她会一条一条蹦消息（用 || 拆条），期间显示“对方正在输入…”。
- 发 [STICKER:名字] 是表情包：齿轮 → 表情，先把图传进去。
- 发 [DRAW:英文描述] 会自己画画（Pollinations 生图）。
- 记忆在 memory_diary.txt，一行一件事，越具体越好；
  聊天里直接发「记一下 他下周三月考」也会写进去。
- 晾她三分钟，她会主动找你说话。
- 大脑默认本机 Ollama：ollama serve + ollama pull qwen2.5:7b。

【日常操作】
1. 双击桌面的“礼貌小狗”快捷方式启动。
2. 单击立绘：打开 / 收起聊天。
3. 按住立绘左键拖动：移动桌宠。
4. 右键立绘：打开聊天、🎤 唱首歌、👂 扒歌学习、设置、隐藏、窗口置顶、大小、开机自启、退出。
5. 对话不占用全局快捷键：点立绘即可开合。语音相关的四个热键（语音输出 / 暂停 / 停止 / 麦克风）在「设置 → 键位」里可以自己改，也可以留空不用。
6. 唱歌相关全局快捷键（同样可在「设置 → 键位」里改）：
   Ctrl+Alt+S  打开设置窗口
   Ctrl+Alt+G  小狗唱歌（打开唱歌台）
   Ctrl+Alt+L  扒歌学习（听原唱自学，自动弹扒歌窗口）
7. 退出：右下角托盘图标右键 → 退出程序。

聊天记录、亲密度、表情包、人设都会自动保存，下次启动还在。
数据目录：%APPDATA%\PolitePuppyPet\

礼貌小狗桌宠 · 使用说明（v2026.11.20）
==========================================

【怎么启动】
双击 01_程序\PolitePuppy.exe，就这样，不用安装、不用构建、不用装 Python。
托盘出现小狗图标，点立绘就能聊天。

⚠ 同一时间只能跑一只小狗。
  如果已经有一只开着，再双击会弹一个框，告诉你"正在运行的是哪个版本、在哪"。
  要换成刚双击的这个版本：先在托盘右键 → 退出，再启动一次。

【你的数据在哪】（重要，先看这段）
记忆、日记、Agent 日志都在**数据目录**里，默认是：
  %LOCALAPPDATA%\PolitePuppyPet\data
（不再放 exe 旁边了——项目常在 OneDrive\桌面下，库一边写一边被云盘同步，有损坏风险）

  ...\data\记忆\memory.db        她记住的事（聊天记录 + 记忆库），最重要
  ...\data\memory_diary.txt      日记，一行一件事，可以直接用记事本改
  ...\data\agent_data\           Agent 干过什么的审计日志
  01_程序\voices\                音色档案（她说话的声音），跟程序放一起
  01_程序\.voice_cache\          语音缓存，删了会自动重建，不心疼
  01_程序\plugins\               Agent 插件目录

  老版本的数据在 01_程序\记忆\ 下：新版本第一次启动会自动**拷**一份到数据目录，
  原件不动（确认没问题后可以自己删）。
  想换地方：设环境变量 POLITE_PUPPY_DATA=<你想放的目录>，重启生效。
  备份 = 把 data 目录 + voices 目录一起复制走。
  卸载 = 删程序目录，再删 %LOCALAPPDATA%\PolitePuppyPet，干净，没有注册表残留。

【日常操作】
1. 双击 01_程序\PolitePuppy.exe 启动。
2. 单击立绘：打开 / 收起聊天窗。
3. 按住立绘左键拖动：移动桌宠。
4. 右键立绘：打开聊天、🎤 唱首歌、👂 扒歌学习、设置、隐藏、
   窗口置顶、大小、开机自启、退出。
5. 聊天不占全局快捷键，点立绘即可开合。
6. 退出：托盘图标右键 → 退出程序。

【全局快捷键】（可在「设置 → 键位」里改，也可以留空不用）
   Ctrl+Alt+S   打开设置窗口
   Ctrl+Alt+G   小狗唱歌（打开唱歌台）
   Ctrl+Alt+L   扒歌学习（听原唱自学，自动弹扒歌窗口）
   语音输出 / 暂停 / 停止 / 麦克风 四个键同样在「设置 → 键位」里配

【她会做什么】
- 一条一条蹦消息（用 || 拆条），期间显示"对方正在输入…"
- 底部快捷回复跟着她的回复变，点一下直接发送
- 发 [STICKER:名字] 是表情包：齿轮 → 表情，先把图传进去
- 发 [DRAW:英文描述] 会自己画画
- 晾她三分钟，她会主动找你说话
- 语音输入：输入框左边的麦克风，中文边说边出字
- 她真的查了东西（时间、文件、记忆）时，气泡下面会挂一枚 🔧 标记，点开看她刚才做了什么

【大脑怎么接】
两种模式，在「设置 → 模型」里切换：

  本地大脑（默认，不需要联网、不需要装任何东西）
    用包内 brain.json 语料，开箱即用，回复短、口语化。

  外部大模型（想让她更聪明再接）
    本机 Ollama：先 ollama serve，再 ollama pull qwen2.5:7b，
    然后在设置里把地址填 127.0.0.1:11434、模型名填 qwen2.5:7b。
    ⚠ 地址一定写 127.0.0.1，别写 localhost（WebView2 有时解析到 ::1，连不上）。

  ⚠ 这几种模式的隐私差别，别搞混：
     本机大脑 / 本地(Ollama) / 演示 —— 不联网，内容不出这台电脑。
     云端(远程 API) —— 会联网：你说的话、她的回复、系统提示词都会发到
       你填的那个接口。第一次切过去会弹一次提示，写清楚都发什么。
       云端模式默认"不带记忆片段"（旧事不跟着出去）；想连旧事一起发，
       才去 设置 → 人设 里把那个开关关掉。
     设置 → 参数 第一行一直写着"现在走本地还是云端"，不用猜。
     不想外发就别在云端模式里让她读文件——文件内容也算系统提示词的一部分。


【常见问题】
问：双击没反应 / 小狗没出现？
答：大概率是已经有一只在小跑了（看托盘）。先退掉旧的再启动。

问：她说的话全是"嗯""哦"？
答：本地大脑语料不够时就会这样。接上 Ollama 的 7B 以上模型会明显好转。

问：白屏？
答：装一下 WebView2 Runtime，Win10/11 一般自带。

问：表情包发不出来？
答：齿轮 → 表情，先传图。她只能用你传过的名字。

问：想让她记得更多？
答：直接跟她聊就行，她会自己记。也可以手动编辑 memory_diary.txt，
    一行一件事，写具体点，比如"2026-10-30 他说下周三要月考，挺紧张的"。
